O curso de Qualificação Profissional de Desenvolvedor Back-End tem por objetivo o desenvolvimento de competências que permite projetar, desenvolver e manter sistemas e aplicativos na parte do servidor e seguindo boas praticas, procedimentos e normas.

###  Banco de Dados

Módulo com foco no desenvolvimento de aplicações que utilizam banco de dados com a técnica ORM realizando as operações CRUD:
- CREATE -> CRIAR
- READ -> LER
- UPDATE -> ATUALIZAR
- DELETE -> DELETAR
Com elaboração de algumas consultas (querys) SQL mas os projetos em sua maioria fora desenvolvidos com ORM -> Objeto Relacional Mapeado
